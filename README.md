# 课序 · 课程管理

响应式 PWA，包含课程增删改、每周重复课表、作业截止日期与完成状态、课时进度、JSON 备份导入导出。首次使用为空数据，通过右上角添加课程开始。

## 本地运行

在本目录执行 `python -m http.server 8080 --directory dist`，浏览器访问 http://localhost:8080。停止时按 Ctrl+C。测试执行 `node test.cjs`。

## 跨平台

Windows、Android 使用支持 PWA 的浏览器打开 HTTPS 地址，在菜单中安装应用。iOS 使用 Safari 打开后选择共享 → 添加到主屏幕。网页也可直接使用。此交付为 PWA 源码，不包含原生 EXE、APK 或 IPA 安装包；尚未在各平台真机验证安装行为。

## 数据与限制

数据保存在当前浏览器 localStorage，刷新后保留。不同设备不自动同步，可通过备份迁移；清除浏览器数据会删除记录，请定期导出。导入前有覆盖确认和结构校验。无账号、推送提醒或云端数据库。课表按星期重复，每条课程记录对应一个固定周课时段。离线功能需要首次成功联网缓存，并依赖浏览器支持 Service Worker。

## 验证

执行 JavaScript 语法检查及 `node test.cjs`：覆盖课程和作业保存、状态更新、无效关联、重复编号、非法进度与时间、HTML 转义、页面渲染和存储失败保留状态。自动测试使用模拟 DOM，不代替浏览器和真机交互测试。
